# 美股期权执行层（Alpaca）说明 · 11d

代码：`desk/alpaca_exec.py`　配置：`config.toml` 的 `[alpaca]`　账本：`data/ledger/alpaca.jsonl`　测试：`tests/test_alpaca_exec.py`

## 它是干什么的

期权研究每次锁定事件样本时，纸面交易员会选一边：A（卖波动）、B（买波动）、C（不动）。
这一层做的事：把 A / B 变成**美股期权**的真实订单，发给 Alpaca 券商；窗口结束时自动平掉。

- **A → 铁蝶式**：卖平值 call + 卖平值 put（这部分就是"卖跨式"），再各买一张离平值约 3% 的 call 和 put 当"翅膀"。
  翅膀的作用是封住最大亏损。举例：SPY 580，卖 580 的 call 和 put 收 $5.10，买 597 call 和 563 put 付 $0.90，
  净收 $4.20 → 每张最多亏 (17 − 4.2) × 100 ≈ $1,280，不会无限亏。
  为什么不直接卖跨式：散户账户基本不让裸卖（亏损没上限），铁蝶是"带保险的卖跨式"。
- **B → 买跨式**：买平值 call + put。最多亏付出去的钱。
- **C → 不下单。** 每日对照样本也不下单，只做事件（CPI / FOMC / NFP / 财报）和突发事件。

标的怎么对：

| 研究里的事件 | 美股标的 |
|---|---|
| CPI / FOMC / NFP | SPY（配置 `macro_underlying` 可改成 QQQ） |
| 财报 EARNINGS:NVDA | NVDA（个股自己的期权） |
| 突发：交易所被盗 / 监管-ETF | IBIT（比特币 ETF） |
| 突发：地缘 / 关税 / 宏观意外 | SPY |
| BTC 本身 | IBIT |

到期日：选"窗口结束之后最早到期"的那一期；行权价：离现价最近的。
张数 = 单笔最多亏（`max_risk_usd`）÷ 每张最多亏，向下取整。**算出来 0 张就不下，并在账本里写原因。**

> 注意：默认 `max_risk_usd = 100`。SPY 的平值铁蝶每张最多亏一千多美元、买跨式每张约 $600，所以按默认值 **SPY 一张都买不起，
> 只有 IBIT 这种便宜标的能下**。想做 SPY 要把上限调到 $1,300 左右——调大以后两人的批准会自动失效，要重新批准。

## 三种模式

| 模式 | 什么时候 | 钱 |
|---|---|---|
| 真钱（live） | 下面 8 条门**全部**打勾 | 真钱，发到 api.alpaca.markets |
| 纸面账户（paper） | 门没全过，但填了 Alpaca 纸面账户的 key | 假钱，但真撮合，发到 paper-api.alpaca.markets |
| 演练（dry） | 门没全过，也没有纸面 key | 不发任何请求，只在账本里写"本来会下什么" |

每一笔都写进账本：用了哪个模式、当时 8 条门各是什么状态、发出去的订单内容、券商回了什么。手机推送的标题里都写明模式（真钱 / 纸面账户 / 演练）。
`[alpaca] enabled = false`（默认）时这一层完全不动。

## 8 条门（全部要过，少一条就退回纸面 / 演练）

1. **配置打开**：`config.toml` 里 `[alpaca] enabled = true` 和 `live = true` 两个都要写。
2. **真钱 key**：服务器上填的是 Alpaca 真钱账户的 key，并且勾掉"这是纸面账户的 key"（即 `ALPACA_PAPER=0`）。
3. **两个人都批准**：Kea 和老板各在服务器上跑一次批准命令。批准时会记下当时的单笔上限和当日止损；之后谁把上限调大，批准自动作废。
4. **回测门**：`data/reports/options_gate.json` 要满足：事件 ≥ 60 个、总净赚 > 0、去掉最赚的 3 笔还 > 0、最差一笔亏损不超过 3 × 单笔上限、不是合成数据。
   这个文件由 `python3 -m desk.options_backtest --market us --underlying SPY --since 2021-01-01` 在服务器上自动写出（只有真实数据的美股口径才写）。
5. **纸面成绩**：研究里已经结算的事件 / 突发样本 ≥ 5 个（每日对照样本不算），并且"按规则选边"的纸面累计盈亏 ≥ 0。
6. **同时最多 1 个真钱仓位**：上一笔没平，新的不开。
7. **当日止损**：今天（美东时间）真钱已实现亏损到了 $100（`daily_loss_stop_usd`），今天不再开新仓。
8. **开盘时间**：Alpaca 时钟说美股开着，并且离收盘还有 10 分钟以上。

前 7 条有一条不过，程序连真钱的网址都不会去碰（测试里逐条验证过）。

## 平仓

- 研究样本 24 小时窗口结束时，程序发一张"反向多腿市价单"一次平掉所有腿。
- 如果多腿单被拒，自动改成逐腿平仓。
- 如果那时没开盘（比如 CPI 窗口在早上 7:30 美东结束），记成"等开盘再平"，开盘后每 15 分钟重试一次。
- 如果合约已经到期，只记录，不再下单（到期按券商规则处理）。
- 紧急情况：`python -m desk.alpaca_exec panic-close` 把账本里所有没平的仓位逐腿平掉。

## 怎么拿 Alpaca key、开期权权限

1. 去 alpaca.markets 注册账户（个人账户就行）。注册好后自动有一个**纸面账户**（Paper Trading），不用入金。
2. 左上角切到 Paper 账户 → 右边 **API Keys** → **Generate New Keys**，复制 Key ID（PK 开头）和 Secret（只显示一次）。
3. 打开网站 **设置 → 美股期权执行（Alpaca）**，填进去，勾"这是纸面账户的 key"，保存。之后所有单子都走纸面账户。
4. 真钱账户要另外做：完成开户审核、入金，然后在账户里申请**期权交易权限**：
   - Level 1：备兑 call / 现金担保 put —— 不够；
   - Level 2：买 call / put —— 够做 B（买跨式）；
   - **Level 3：价差（spread）—— A 的铁蝶式要这一级。** 申请时要填交易经验和资产，审核可能拒；被拒的话就只能做 B。
5. 真钱账户的 key 和纸面账户的 key **不是同一套**。真钱 key 是 AK 开头，在真钱账户界面生成。
   想同时保留纸面 key，可以在服务器 `.env` 里另放 `ALPACA_PAPER_KEY_ID` / `ALPACA_PAPER_SECRET`。

## 为什么不用 Robinhood

Robinhood 没有给个人用的期权下单 API（官方只开放了加密货币的 API），用程序下单只能靠非官方的逆向接口，随时会坏、还可能违反用户协议被封号。
Alpaca 是专门给程序交易用的券商，有正式的期权 API 和完全一样的纸面账户，所以先在 Alpaca 上把整条流程跑通。

## 第一笔真钱之前，Kea 和老板要做的事（按顺序）

1. **Kea**：注册 Alpaca，拿纸面 key，填到网站设置里；把 `[alpaca] enabled = true`（`live` 先保持 false）。从这时起所有事件单走纸面账户。
2. **Kea**：在纸面账户里至少看一笔铁蝶的下单和平仓推送，到 Alpaca 网页上核对成交（尤其是限价的正负号、市价平仓是否被接受，见下面"还不确定的地方"）。
3. **服务器**：跑一次美股回测，生成 `data/reports/options_gate.json`，看是否通过。
4. **等研究攒够**：至少 5 个已结算的事件 / 突发样本，按规则选边累计不亏。
5. **Kea**：开真钱账户、入金、申请期权 Level 3（或至少 Level 2）；在设置里换成真钱 key，**取消勾选**纸面账户。
6. **两人商量好** `max_risk_usd`（单笔最多亏多少）和 `daily_loss_stop_usd`，写进配置。
7. **Kea** 在服务器上跑 `python -m desk.alpaca_exec approve --who kea`；**老板**跑 `python -m desk.alpaca_exec approve --who boss`。
8. 把 `[alpaca] live = true`。跑 `python -m desk.alpaca_exec status`，8 条都打勾（开盘那条只在开盘时检查）才算准备好。
9. 第一笔下单后盯着手机推送；有任何不对就 `python -m desk.alpaca_exec panic-close`，再把 `live` 改回 false。
   撤销批准：`python -m desk.alpaca_exec approve --who kea --revoke`。

## 还不确定的地方（先在纸面账户验证）

- **多腿单限价的正负号**：程序按"正数 = 付钱（买跨式），负数 = 收钱（铁蝶）"来写。Alpaca 文档页的例子只有正数。如果纸面账户里铁蝶被拒或成交价离谱，改 `price_structure()` 里的 `limit_price`。
- **多腿市价单**：文档例子只有限价单。平仓先发多腿市价单，被拒就逐腿平（已写好兜底）。
- 开仓用买卖中间价挂限价单、当天有效：没成交就是没做，不追价。账本里的盈亏是按中间价估算的，以券商成交为准。
- 回测门用的是"裸卖跨式"的回测结果，比铁蝶更保守（铁蝶的最大亏损更小）。盈亏按 `[options.paper] notional_usd` 名义金额计，和真实张数不完全对应。
