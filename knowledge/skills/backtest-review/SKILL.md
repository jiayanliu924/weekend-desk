# 回测审查清单（怀疑派用）

先写结论再逐项查。任何一项命中都要写明证据位置。

## 1. 前视偏差（look-ahead）
- 入场、出场、估值是否都只用当天 ≥15:50 ET 的最后一条报价？之后或收盘后的数据不得使用。
- IV30 是否只用 15:59 前的最后报价？
- 信号里的实际波动是否只用 d−1 及以前的收盘（RV20 = d−20 … d−1）？
- 财报日期是否来自带出处的历史文件（knowledge/earnings_history.json）？
- 方案参数是否在看结果前已登记（v2 toml 的写法）？
- LLM 类策略：agent 是否只看到决策时点前的数据？底稿提示这类回测极易泄漏（TradingAgents 的更新日志多为时点修复）。

## 2. 成交真实性（fill realism）
- 主口径是否卖按 bid、买按 ask，并计每张每腿 $0.65 与 1% 权利金滑点？
- 只在参考口径（75% / 50% 价差）下赚钱的策略，不得直接上钱。
- 成本敏感性：成本放大到 1.0 倍、1.25 倍报价价差后，结论是否还成立？（Vasquez 的成本后结果在 1.25 倍时即不显著。）
- 流动性过滤是否执行：每腿 (ask − bid) ≤ max(15% × 中间价, $0.05)，否则不开？
- 估值用中间价的结果，是否另有按买卖价成交的主口径结果？

## 3. 交易剔除与幸存者
- 有没有剔除亏损笔、异常日、某个标的或暴跌期？任何"剔除异常"都算作弊（v2 toml）。
- 是否报告最差一笔、最大连续亏损笔数、2024-08-05 与 2025-04 两段各自盈亏、按标的拆分？
- 同一标的 5 个交易日内的入场是否合并为 1 簇？簇数是否 ≥ 10？
- 标的是否按事先规则选入，而不是看回测排名挑？（17 只单票是按流动性规则加入，未看排名。）

## 4. 多重检验
- 累计试验次数多少？v1 32 + v2 28 = 60，Bonferroni 门槛 0.05/60。
- 是否报告 Deflated Sharpe（按累计试验次数校正）？开发段 DSR 须 > 0。
- 候选集的 PBO（CSCV）是否 < 0.5？
- 门槛是否敏感？只在某个参数格子好看，是多重比较的典型信号；门槛不敏感才可信（17 只单票上四个门槛全部样本外通过，是这类例子）。
- 同一数据窗口反复"择优替换"，视为没有校正的数据窥探（R3 的推断，RD-Agent 的 SOTA 循环有此风险）。

## 5. 暴跌与行情切换
- 样本是否包含 2024-08-05 与 2025-04？缺一则 FIX。
- 两段暴跌期间的盈亏、最大亏损倍数是否报告？暴跌期亏损超过最大亏损 3 倍即罚分。
- 分时段表现是否前后翻转？翻转要区分行情切换与噪音，样本少时不下结论。

## 6. "好得离谱"（先当 bug 查）
- 考试段每笔平均 > 最大亏损的 40%，或胜率 > 95% 且样本 ≥ 30：先查 bug。
- 收益是否超出底稿的现实区间？公开卖波动基金多在年化 8–22%；周 10%、月 30–50% 没有可核实的长期先例。
- 宣传文案、单年比赛结果不采信（底稿：Benzinga 文案无交易记录；US Investing Championship 单年、自选参赛，有幸存者偏差）。
- 对照组：财报买方跨式（14DTE 以上）应亏。若它赚，说明回测口径有误。

## 7. 仓位与单位
- 收益是否换算成账户口径（每笔占最大亏损 × 风险档 2% / 5% / 10%）？占期权价格的收益不能直接当账户收益。
- 同日 index_like 价差是否合计风险 ≤ 单档 × 3？

## 判决
- SHIP：全部通过，且考试段与前向段达标（见 v2 toml [pass]）。
- FIX：有可修的问题（前视、成本口径、缺暴跌段、缺报告项）。写明要改哪一条。
- SCRAP：多重检验后不显著，或样本外为负，或属于"好得离谱"且无法解释。
