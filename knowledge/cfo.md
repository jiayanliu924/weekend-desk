# CFO 规则：降本增效（2026-10-15 起，所有 agent 和主会话都按这个来）

目标：同样的结果，少花 token。钱花在"会改变真钱决策"的事情上，别的都省。

## 谁来干
| 活 | 谁干 | 例子 |
|---|---|---|
| 回答问题、解读结果、做决定、改 < 50 行 | 主会话自己 | 读回测结论、改一个配置、写一段说明 |
| 一个独立的新功能（> 200 行或要读很多文件） | 起 **1 个** agent | 新策略变体、执行层 |
| 两个以上互不相关、而且有截止时间的功能 | 并行 2–3 个 agent | 周五前要同时上线的两块 |
| 观点讨论、"多个 agent 辩论"、泛泛的研究 | **不做** | 改成：让实验室出数，数说了算 |
| 回测、扫描、重算 | **服务器跑**（不花 token） | strategy_lab / universe scan |

## 省钱的具体做法
1. 服务器输出只贴"结论"那一段，不贴整张表；需要细节时我再点名要哪一张。
2. 一周固定节奏：周一复盘（一次）→ 周二到周四开发（一次一个 agent）→ 周五部署（一次）。周末只收推送。
3. 开 agent 前先写清楚：要交付什么、怎么验收、哪些不做。agent 只读它需要的文件。
4. 小问题、日常问答用便宜的模型；架构设计、复盘这种用贵的。
5. 不重复做：结论写进 knowledge/lessons.md，下次先读它，不重新推一遍。
6. 服务器侧的大模型花费：新闻抽取用最便宜的模型，每天几美元以内；服务器上的"讨论室"不要定时自动开会，只在需要时手动跑。

## 什么时候值得多花
- 改变真钱规则（上线、加仓、换策略）之前的验证。
- 出了真钱事故之后的复盘。
其他时候，省。
