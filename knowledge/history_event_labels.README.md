# 历史周末 / 夜间大事件标签集（2019–2026）

文件：`knowledge/history_event_labels.json`（63 条，2026-10-12 整理）。手工挑选、逐条附公开来源。
用途：给"头条动量影子线"（desk/headline_shadow.py）和 agent 团队一个**可查的先验**——某类新闻出来后，第一个交易时段的跳空到底是延续还是回吐。它不是回测数据，数字精度只到"方向 + 大致幅度"。

## 字段

| 字段 | 含义 |
|---|---|
| `event_id` | 唯一 id，`slug-YYYY-MM-DD` |
| `date_utc` | 事件发生/公开的 UTC 时间（近似到小时） |
| `weekend` | 真市场关门期间发生（周五收盘后到周日/周一重开前），或周一开盘前的亚洲时段 |
| `event_status` | `concluded`：事件本身已经完成、不会再升级（一次袭击打完、一份决议通过、一次会议开完）；`ongoing`：事件仍在进行、后续可能升级或反复（战争、谈判未定、报复悬而未决、挤兑进行中） |
| `category` | `geopolitical_oil` / `geopolitical_broad` / `macro_policy` / `sanctions` / `opec` / `corporate_single_name` / `crypto_native` / `natural_disaster` / `pandemic` |
| `entities` | 涉及的品种/地区/公司（大写），和抽取器的 entities 同口径，可直接喂 `desk/relevance.py` |
| `materiality` | 1–3，和抽取器口径一致 |
| `initial_direction` | 品种 → 新闻出来后**第一反应**的方向（up/down） |
| `reopen_move_bps` | 品种 → 事件后**第一个完整交易时段收盘**相对事件前收盘的变动（万分点）。周末事件 = 周一收盘 vs 周五收盘；夜间事件 = 次日收盘 vs 前一日收盘 |
| `move_90min_bps` | 重开/首个成交后约 90 分钟内的变动；没有可靠数据填 `null` |
| `reversal_within_2d` | 事件后 2 个交易日内，价格回到事件前水平的另一侧，**或回吐首次反应的一半以上** |
| `confidence` | 数字可靠度 high/medium/low（low = 来源只给方向、幅度是我估的） |
| `sources` | 至少一条公开链接 |
| `notes` | 为什么延续/反转、有什么坑 |

## 核心统计：地缘/油价事件，跳空是延续还是回吐？

按 `category == geopolitical_oil`（17 条）、按 `event_status` 分：

| 状态 | 条数 | 两日内反转 | 延续 | 反转的 | 延续的 |
|---|---|---|---|---|---|
| **concluded 已结束** | 11 | **8** | 3 | Abqaiq 2019、伊朗导弹 2020-01-08、美英打胡塞 2024-01、伊朗无人机 2024-04-13、Isfahan 2024-04-19、纳斯鲁拉 2024-09、Fordow 2025-06-21、Fujairah 2019-05 | 以色列打伊朗避开油设施 2024-10-26（方向向下，延续）、停火 2025-06-23（向下，延续）、阿曼湾油轮 2019-06 |
| **ongoing 进行中** | 6 | **1** | 5 | 哈马斯 2023-10-07（两日回吐 2/3，之后又涨） | Soleimani 2020-01、俄油禁运传闻 2022-03-06、伊朗导弹 2024-10-01、以色列打伊朗 2025-06-13、胡塞利雅得 2026-10-10 |

只看周末发生的（`weekend == true`）：已结束 6 条里 5 条反转；进行中 3 条里 1 条反转。

扩展到全部 63 条：已结束 40 条里 25 条反转（62%）；进行中 23 条里只有 2 条反转（9%）。

### 怎么读

1. **"已结束"的袭击，跳空大多两日内回吐**：袭击打完、产量/航道没有持续损失，周日晚的溢价是情绪，周一就被卖掉（Abqaiq 是极端：涨 20%、两周归零；Fordow：周日晚 +5.7%，周一 -7.2%）。
2. **"进行中"的冲突，跳空大多延续**：报复悬而未决（Soleimani、2024-10-01）、战争刚开（2025-06-13）、航道还在被打（2026-10-10），溢价至少撑两天。
3. **已结束但延续的 3 条，有 2 条方向是向下**（打击避开油设施、停火）——"坏消息已经过去"这种利空油价的消息不会反弹。所以对油价而言，**空头方向的头条动量比多头更可靠**。
4. **方向本身也会猜反**：伊朗无人机 2024-04-13（事先预告、拦截率 99%）周一油价反跌；飓风 Ida 原油反而弱（炼厂停工）；美联储 2020-03-15 紧急降息股指跌停。影子线只按原文倾向定方向，这些就是它会亏的地方——正是要攒的证据。
5. **2026-10-10 这条是"先反转、后延续"**：ICE 周日 +0.2% 后 90 分钟 -1.5%，夜盘比周五锚低 3%，周一新袭击又把价格推回锚之上。`move_90min_bps` 和 `reopen_move_bps` 符号相反，正是为了记录这种形态；头条动量影子线的 +1h 和 +24h 账会分开算。

### 对影子线的直接含义

- 抽取器的 `event_status` 字段（2026-10 新增，默认 unknown）就是为了复现这张表：如果实盘记账也呈现"已结束→反转、进行中→延续"，可以考虑把"已结束 + 多头方向"的头条动量反过来做（做反转），把"进行中"的顺势做。
- 样本量：17 条油价事件、6 条周末已结束事件——只够提出假设，不够下结论。影子线自己至少要攒 20 条新头条再谈。

## 数据来源与局限

- 幅度数字来自新闻报道（Reuters/AP/彭博转载、CNBC、S&P Global Platts、各地财经媒体），不是逐笔数据；盘中极值和 90 分钟变动尤其粗糙。
- `reversal_within_2d` 的判断是人工的，按上面的定义；边界案例（哈马斯、俄乌首日）在 `notes` 里说明了取舍。
- 2026-10-10 一条的 HL 价格来自本系统采集（周五锚 103.08、周末区间 102.0–103.3、周一 11:10 PT 104.25），ICE 数字来自来源链接。
- 没有收录纯工作日盘中事件（如 2025-04-09 暂缓关税 +9.5%），因为本数据集只关心"真市场关着的时候出的事"。
