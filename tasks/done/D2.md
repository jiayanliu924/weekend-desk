# 卡 D2（中档）Databento 期权 1 分钟报价下载器
- 新增 desk/opra_fetch.py、tests/test_opra_fetch.py；config.toml 新增 [opra] max_cost_usd = 100。
- 流程：Alpaca 免费取不复权日收盘 + 全部标准合约（含已到期，跳过 1XYZ 调整合约）→ 每天选 到期 d+14..d+60、行权价 ±10% 的合约 → 收盘前 30 分钟（半天市用 /v2/calendar 的 13:00，拿不到日历就按 16:00）。
- OCC 转 OSI（根代码补到 6 位 + yymmdd + C/P + 8 位行权价，21 位），有单测。
- 请求 = 每个(交易日, ≤2000 符号块)。--plan 默认抽样估价：每个(标的,月)精确问 3 个均匀间隔交易日，按该月交易日数放大，合计 x1.2 安全边际与上限比较；--exact 才逐请求询价（无边际）。并发 ≤4，429 指数退避重试。
- --plan 只打印；--download 需 --yes 且总价 ≤ [opra] max_cost_usd，否则中止（退出码 2）。
- 下载逐 (标的, 月) 处理（省内存），存 data/opra/cbbo1m/<UND>/<YYYY-MM>.parquet（ts,symbol,bid_px,ask_px,bid_sz,ask_sz；价格转美元浮点）；先写 .tmp 再改名；已有文件跳过（续跑，且不再计入费用）。
- 元数据存 data/opra/meta/：closes_<UND>.json、needed_<UND>.json（每天需要的合约）、needed_monthly_<UND>.json（按月并集）、download_log.jsonl。
- Databento API 不返回实际扣费，日志里记的是预计花费。
- 未实测：本机无网络，只用假 Alpaca/Databento 测过；cbbo-1m 的列名(bid_px_00 等)、get_cost 请求数量（约 700 天×8 标的×1~2 块，询价较慢）待服务器首次 --plan 验证。
- 用法：venv/bin/python -m desk.opra_fetch --plan ；确认价格后 --download --yes。
- 全部测试通过（python3 -m pytest -q tests/）。未提交。
