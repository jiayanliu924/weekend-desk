# Weekend Desk

按研究备忘《把世界整理成表格》第七、八章做出来的周末价格发现系统。

**它做的事：** 每个周末盯着 Hyperliquid 上的 XYZ100（跟纳斯达克 100 走的永续合约），读周末新闻，在周日晚外部价格恢复前 15 分钟锁定一个预测和一笔模拟交易，重开后自动对答案、记账，周一给你发周报。

## 期权研究模块（备忘第九章）

**问题：** 美联储议息、CPI、非农这些事件之前，期权价格里隐含的波动，是不是总比随后实际走出来的波动偏高或偏低？

- **数据**：Deribit 的 BTC 期权报价（每 5 分钟，只存 10 天内到期、行权价在现价 ±10% 以内的）和 BTC 指数价（每分钟），都是免费公开数据。
- **事件样本**：`events.toml` 里的每个事件，提前 60 分钟锁定"未来 24 小时的隐含波动"，24 小时后用指数价算实际波动，比较两者。
- **对照组**：每天 08:00 UTC 也锁定一次。窗口里没有事件的日子是对照组，用来回答"事件日和普通日到底有没有区别"。
- **大模型的角色**：锁定前把过去 24 小时的新闻抽成事件表（突发宏观、监管、地缘事件数作为特征）；事件后 3 小时内，从新闻里抽"实际值 vs 预期"的意外程度，供复盘。
- **怎么读结果**：实际/隐含 < 1 说明期权定价偏贵（实际波动小于隐含），> 1 说明偏便宜。
- **不做的事**：不下单、不做市、不卖期权（备忘第九章原文）。

接下来的事件：CPI 10/14、议息 10/28、非农 11/6、CPI 11/10、非农 12/4、议息 12/9、CPI 12/10。BLS 公布 2027 年日程后，把 CPI 和非农补进 `events.toml`。

## 安装（大约 15 分钟）

1. **租服务器**：在 DigitalOcean 建一台最便宜的 Droplet（Ubuntu 24.04），记下 IP 和 root 密码。
2. **把程序传上去**：在你 Mac 的"终端"里执行（把 `IP` 换成你的服务器 IP）：
   ```
   scp ~/Downloads/weekend-desk.zip root@IP:/root/
   ssh root@IP
   ```
3. **在服务器上安装**：
   ```
   apt-get install -y unzip && unzip weekend-desk.zip && bash weekend-desk/install.sh
   ```
   中途会让你粘贴 Anthropic API Key，用来读新闻。
4. **手机装 ntfy App**，订阅安装结束时打印的频道名。

## 常用命令（在服务器上，先 `cd /opt/weekend-desk`）

```
./venv/bin/python -m desk status                  看数据有没有在进、新闻源是否正常、当前成绩
./venv/bin/python -m desk note "materiality 阈值由 2 改为 3"   周五收盘前写本周"假设与改动"
./venv/bin/python -m desk review 2026-10-09 "周六一条监管新闻漏抓，来源未接入"   周一复核
./venv/bin/python -m desk report                  立刻生成周报
./venv/bin/python -m desk check-llm               抽检最近 5 条新闻的抽取结果
```

改 `config.toml` 只能在周一复核时做，改完执行 `systemctl restart weekend-desk`。

## 费用

服务器每月约 6 美元。大语言模型用 Haiku：周末模块只读周末窗口内的新闻，期权模块每天读一次过去 24 小时的新闻（每次最多 60 条），合计每月大约 5–10 美元。

## 已知限制

- 新闻源用的是免费 RSS，X（推特）列表需要付费接口，暂未接入。某个源失效时 `desk status` 会显示 ✗。
- 节假日休市（感恩节等）暂按普通工作日处理，只做周末。
- 周末模块的正式结论要等 30 个正式周末，大约 7 个月；期权模块要 20 个事件，大约一年（每日对照组会快很多）。之前任何漂亮的结果都只算"值得继续看"（备忘 7.5）。
